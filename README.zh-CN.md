# 审美 DNA

**你的目光，自有主张。**

[直接体验](https://mikechengx.github.io/aesthetic-dna/) · [English](README.md) · [架构说明](docs/ARCHITECTURE.md) · [素材与来源](ASSETS.md)

一个通过选择与创作观察个人视觉偏好的小实验。从真实电影海报出发，探索构图、建筑、服装、配色和排版，最后生成包含「你的侧重、创作思路、创作气质」的审美档案，并保存一张有设计感的结果卡。

![植物档案、摄影刊物与实验海报三种原创结果卡](docs/images/result-series.png)

## 这版包含什么

- 开场扩展到 **16 张真实电影海报**，包含欧美、韩国、日本电影。可筛选「极繁冲击、干净留白、日式美学、手绘世界」，顺序按本次实验打散，最多选三张。
- **右上角 EN / 中文切换**，默认英文；题目、报告、作品文字和导出跟随语言切换，作答与编辑进度保留。
- 16 步视觉实验，约 6–10 分钟。可以跳过、返回修改和暂存离开。
- 摄影练习替换为 **东方明珠人像、海岸旅行人物、山湖风景**，东方明珠可切换平视与低机位素材，再选择人物优先、地标同框或环境优先的取景起点。四张 AI 写实素材内嵌，支持离线裁切与导出。详见 [素材与提示词](docs/PHOTOGRAPHY.md)。
- 九道偏好题加入可跳过的具体理由追问。同样的选图可以留下不同关注点，理由不会重复计分。
- 报告增加跨场景配色对照、反复关注的理由、机位与实际裁切面积、三色比例，并给出对应练习。
- 动手取景、三色面积分配、海报编排与单件搭配。38 种颜色、HEX 输入、8 套配色起点。
- 根据本次实际选择生成有证据可追溯的报告；草稿与确认答案分开。
- 植物档案、摄影刊物、实验海报三种完整结果卡；统一主色，搭配纸白、暖色与不同字体层次。
- PNG 保存审美卡与单件作品；Markdown 下载完整报告。
- 浏览器本地保存，无需账号、API 密钥或后端。

这是趣味视觉实验，没有人格诊断或审美总分。鲜艳配色不会直接推导创造力，跳过创作也不会被解释成「没想法」。

## 本地运行

需要 Node.js 22.18 及以上，CI 使用 Node.js 24。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址，通常是 `http://127.0.0.1:5173`。

```sh
npm run build
npm run preview
```

`dist/` 可部署到静态网站服务。`dist/审美DNA.html` 是内嵌代码、样式和原创图形的单文件版本，可直接打开；真实电影海报仍从发行方加载，需要网络。加载失败时保留片名与官方来源入口。普通 `dist/index.html` 需要通过 HTTP 服务访问。

## 架构与验证

界面已按首页、海报墙、实验工作室、报告拆分；状态、规则、翻译与导出独立组织。英文与中文共用同一套答案和证据，不会因为切换语言改变分析结论。详见 [架构说明](docs/ARCHITECTURE.md)。

```sh
npm test
npm run build
npm run format:check
```

启动开发服务后，另一个终端运行浏览器回归：

```sh
npx playwright install chromium
npm run test:e2e
```

已有 Chrome / Chromium 时自动使用，也可设置 `CHROME_PATH`。测试覆盖中英文完整流程、切换语言保留进度、海报筛选、手机排版、导出、刷新恢复、练习副本和删除。自动测试使用明确标注的原创海报占位图，真实链接另外检查，避免发行方短暂不可用影响测试。

## 记录与素材

答案和作品参数保存在本浏览器，语言偏好也在本地保存。没有统计埋点或云端上传；加载官方海报会向其发行方发送正常图片请求，预览设置了 no-referrer。只保留最近一次实验，重测或清理网站数据前请先导出。

仓库只保存电影海报的目录、官方图片链接与署名，不打包第三方海报原图；海报版权归各权利人。其他插画与结果卡图形由项目原创。新取景练习采用 AI 生成的写实场景与虚构人物；机位切换使用预生成的不同视角素材，拖动和缩放调整当前画幅。本版未接实时 3D 场景、相机或照片识别。旧版插画作品继续保留；参考构图为预设框。详见 [素材清单](ASSETS.md)。

文档预览来自虚构测试作答与原创图形，不包含真实用户数据。
